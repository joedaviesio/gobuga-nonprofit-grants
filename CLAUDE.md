# Focus Guard

When you see `[Focus Guard]` context injected into the conversation, use it to guide work prioritization:

- If the user starts a task in a **different area** from the hot zone, gently suggest they consider finishing nearby work first. Frame it as a suggestion, not a blocker — e.g. "You've got uncommitted changes in X — want to wrap that up first, or park it and switch?"
- If the user is working **within** the hot zone, say nothing — just proceed.
- Never block the user. If they want to switch, switch. The nudge is a one-time suggestion per topic change, not a recurring nag.
- Keep the nudge short — one sentence max.
